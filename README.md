1. Introduction

The Online Quiz System is a web-based application developed to conduct quizzes through an online platform. It allows users to answer multiple-choice questions and automatically calculates the score after the quiz is completed. The system is designed to make the quiz process simple, fast, and efficient compared to traditional paper-based exams.

This project helps students test their knowledge and provides instant results. It also reduces manual effort in checking answers and calculating scores.

2. Objective

The main objectives of the Online Quiz System are:

To provide an easy platform for conducting quizzes online.

To automatically calculate and display the score.

To allow users to answer multiple-choice questions.

To save time and reduce manual checking.

To create a user-friendly interface for quiz participants.

3. Technologies Used

The project is developed using the following technologies:

HTML – Used to design the structure of the web pages.

CSS – Used for styling and improving the appearance of the application.

JavaScript – Used for quiz logic, timer functionality, and score calculation.

Local Storage – Used to store quiz questions and user information.

4. System Features
1. User Login

Users enter their name before starting the quiz. This helps personalize the quiz experience.

2. Multiple Choice Questions

The quiz consists of multiple-choice questions where the user selects the correct answer from given options.

3. Timer

A timer is implemented using JavaScript to limit the time for completing the quiz.

4. Automatic Score Calculation

Once the quiz is submitted, the system automatically checks the answers and calculates the score.

5. Result Display

After submission, the system displays the final score of the user.

6. Admin Panel

The admin can add new questions and options which are stored in the system.

5. Working of the System

The user enters their name on the login page.

The quiz page displays the list of questions with multiple options.

The user selects the answers and submits the quiz.

The system compares the selected answers with the correct answers.

The total score is calculated automatically.

The result is displayed on the screen.

6. Advantages

Easy to use interface

Saves time in conducting exams

Instant result generation

Reduces manual work

Accessible from any device with a browser
